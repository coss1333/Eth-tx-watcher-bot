# Пошаговая инструкция (установка и запуск)

Ниже — простой способ поднять бота на любом сервере/ПК (Windows, Linux, macOS).

---
## 1) Подготовка окружения

1. Установите Python 3.10+ и pip.
2. Скачайте файлы проекта (или возьмите ZIP-архив из этого чата) и распакуйте.
3. В терминале перейдите в папку проекта и создайте виртуальное окружение:
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

---
## 2) Настройка ключей (BotFather + провайдер Web3)

1. В Telegram создайте бота у @BotFather и получите токен `TELEGRAM_TOKEN`.
2. Создайте проект в Infura/Alchemy (или другом провайдере) и получите WebSocket/HTTP endpoint для Ethereum mainnet.
3. Скопируйте `.env.example` в `.env` и заполните значения:
   ```env
   TELEGRAM_TOKEN=ВАШ_TELEGRAM_ТОКЕН
   WEB3_PROVIDER_URI=wss://mainnet.infura.io/ws/v3/ВАШ_PROJECT_ID
   CHAIN=mainnet
   POLL_INTERVAL=6
   DATA_FILE=wallets_db.json
   ```
   *Рекомендуется WebSocket URI (`wss://...`) для более стабильной работы.*

---
## 3) Запуск бота

Выполните:
```bash
python bot.py
```

Если всё ок — бот запустится и начнёт опрашивать новые блоки. Оставьте процесс запущенным.

---
## 4) Использование бота в Telegram

- Откройте чат с вашим ботом и отправьте `/start`.
- Добавьте адрес в отслеживание:
  ```
  /add 0x1234...ABCD
  ```
- Посмотреть список:
  ```
  /list
  ```
- Удалить адрес:
  ```
  /remove 0x1234...ABCD
  ```
Бот пришлёт уведомление, если обнаружит транзакцию с участием любого добавленного адреса.

---
## 5) Советы по продакшн-развёртыванию

- Запуск как сервис (systemd) или через PM2/forever/supervisor — чтобы бот автоматически перезапускался.
- Переход с JSON-файла на БД (PostgreSQL/Redis) при большом количестве чатов и адресов.
- Обработка переподключений к WebSocket (retry/backoff), логирование в файлы.
- Добавление отслеживания ERC-20 `Transfer` событий (через логи) — легко расширить в `scan_loop`.

---
## 6) Частые вопросы

**Q:** Нужен ли публичный сервер?  
**A:** Нет, бот работает через long-polling и исходящее соединение к Web3-провайдеру. Достаточно машины с интернетом.

**Q:** Можно ли сделать отслеживание только входящих/исходящих?  
**A:** Да, отфильтруйте по `from` или `to` в цикле сканера.

**Q:** Где хранятся адреса?  
**A:** В `wallets_db.json` (по умолчанию). Для надёжности используйте БД.
