# Telegram бот — отслеживание транзакций Ethereum

Этот бот следит за новыми блоками и присылает уведомления, если `from` или `to` транзакции совпадает с добавленными адресами.

## Файлы
- `bot.py` — основной скрипт бота
- `requirements.txt` — зависимости
- `.env.example` — пример настроек (скопируйте в `.env`)
- `INSTRUCTIONS_ru.md` — пошаговая инструкция по установке и запуску

## Команды бота
- `/add 0x...` — добавить адрес
- `/remove 0x...` — удалить адрес
- `/list` — показать список адресов
- `/help` — помощь
